Dokumentasi Integrasi API

Panduan integrasi standar OpenAI SDK & cURL untuk aplikasi Anda.

POST https://api.zyvenox.tech/v1/chat/completions
AUTH Authorization: Bearer <API_KEY>
BASH / CURL 
curl https://api.zyvenox.tech/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $ZYROUTER_API_KEY" \
  -d '{
    "model": "gemini-2.5-flash",
    "messages": [
      {"role": "system", "content": "You are a helpful assistant."},
      {"role": "user", "content": "Halo! Siapa namamu?"}
    ]
  }'
PYTHON (openai SDK >= 1.0) 
from openai import OpenAI

client = OpenAI(
    base_url="https://api.zyvenox.tech/v1",
    api_key="YOUR_ZYROUTER_API_KEY"
)

response = client.chat.completions.create(
    model="gemini-2.5-flash",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Halo, jelaskan apa itu Zyrouter."}
    ]
)

print(response.choices[0].message.content)
JAVASCRIPT / TYPESCRIPT 
import OpenAI from 'openai';

const client = new OpenAI({
  baseURL: 'https://api.zyvenox.tech/v1',
  apiKey: process.env.ZYROUTER_API_KEY,
});

async function main() {
  const completion = await client.chat.completions.create({
    model: 'gemini-2.5-flash',
    messages: [{ role: 'user', content: 'Halo dari Node.js!' }],
  });

  console.log(completion.choices[0].message.content);
}

main();
PYTHON STREAMING 
from openai import OpenAI

client = OpenAI(
    base_url="https://api.zyvenox.tech/v1",
    api_key="YOUR_ZYROUTER_API_KEY"
)

stream = client.chat.completions.create(
    model="gemini-2.5-flash",
    messages=[{"role": "user", "content": "Tuliskan puisi singkat tentang cyber."}],
    stream=True
)

for chunk in stream:
    content = chunk.choices[0].delta.content or ""
    print(content, end="", flush=True)

Status Arti Penjelasan / Solusi
401 Unauthorized API Key tidak valid, sudah dicabut (revoked), atau format header salah.
403 Forbidden Model alias tidak diizinkan untuk tier/akun Anda. Hubungi support jika perlu upgrade.
409 Conflict Sudah ada active key yang sedang berjalan saat meminta key baru.
410 Gone Secret key tidak dapat di-reveal ulang. Lakukan rotate jika secret hilang.
429 Rate Limited Melebihi batas RPM/TPM akun Anda. Harap beri jeda sebelum request ulang.
5xx Gateway Unavailable Upstream gateway sedang mengalami kendala sementara. Respons sanitasi aman.
